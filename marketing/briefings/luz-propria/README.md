# Briefings para a Luz Própria

Briefings de campanha, pautas de reunião mensal, cobranças e feedback sobre relatórios e propostas.
Um arquivo por campanha ou reunião: `AAAA-MM-DD-<tema>.md` (modelos em `../../modelos/briefing-agencia.md`
e `pauta-reuniao-agencia.md`). Status no topo: rascunho [aguardando Vitor] · aprovado · enviado.
Nada daqui é enviado pelos agentes; o Vitor envia.
